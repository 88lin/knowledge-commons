# 06 · 合规与税务手册（境内+跨境，2026-10 版）

> 核查日期 2026-10-08。税收优惠政策现行窗口**至 2027-12-31**（财政部/税务总局公告延续期），申报时以当期政策为准。本章是"开店前必读"——尤其第 2 节 810 号令。

---

## 1. 主体注册：先办照，再开店

### 1.1 什么情况可以不办照
《电商法》第十条例外：个人销售**自产农副产品、家庭手工业产品**，或**零星小额交易**（额度授权地方规定，普遍按年交易额 ≤10 万掌握），以及便民劳务——不需要登记。一旦持续经营、超额度，就应登记。

### 1.2 选什么主体
| 主体 | 适合 | 责任 | 税 |
|---|---|---|---|
| **个体工商户** | 新手首选：成本低、税负低、可入驻抖音/微信/小红书/速卖通/Temu/TikTok 东南亚 | 无限责任 | 增值税小规模 + 经营所得税（优惠多，见 §2） |
| 个人独资企业 | 已被核定征收收紧，新手别碰 | 无限责任 | 同上但更复杂 |
| 有限公司 | 要做品牌/融资/亚马逊/投标/多平台矩阵 | 有限责任 | 增值税+企业所得税25%（小微优惠）+分红税，双重视负 |

**结论**：起步办**个体户**，年流水破百万或要上亚马逊再升公司。

### 1.3 个体户线上办理（免费，1–3 个工作日）
1. 入口：本省政务服务网/"一网通办"或当地市监局 APP（浙江"浙里办"、广东"粤商通"等），也可支付宝搜"个体工商户登记"
2. 材料：身份证 + 经营场所证明（**用住宅即可**；做电商还可用《电商法》允许的"网络经营场所"登记——用平台出具的网店经营场所证明，无需实体店面，各地细则不同，选"网络经营场所登记"选项）
3. 流程：名称自主申报（如"XX市XX电子商务工作室"）→ 填经营信息（经营范围勾选"互联网销售"+具体类目）→ 实名认证 + 电子签名 → 等待核准 → 领取电子执照
4. 费用：登记免费；刻章约 ¥100–300（可先不刻）；**对公账户**：个体户可绑定经营者个人银行卡收款，多数平台不强制对公——但公司主体必须对公
5. 税务：领照后税务登记自动同步/30 日内完成，选**小规模纳税人**，按季申报（可自学电子税务局，或找代账 ¥100–200/月）

## 2. 境内税务：810 号令时代，合规成本其实很低

### 2.1 先记住：2027 年底前的优惠窗口（现行政策）
| 税种 | 政策 | 依据 |
|---|---|---|
| 增值税 | 小规模纳税人适用 **1%** 征收率 | 财政部/税务总局公告 2023 年第 19 号，延续至 **2027-12-31** |
| 增值税免征 | **月销售额 ≤10 万（季度 ≤30 万）免征增值税**（开专票部分除外） | 同上 |
| 经营所得税 | 个体户年应纳税所得额 **≤200 万部分减半征收**（法定五级累进 5%–35% 的基础上减半） | 2023 年第 12 号公告，至 2027-12-31 |
| 六税两费 | 小规模/个体户资源税、城建税、印花税等减半 | 同窗口期 |

**算一笔账**：个体户月均销售额 5 万（年 60 万）→ 增值税：季度 15 万 <30 万，**免**；经营所得税：年应税所得（收入−成本费用）假设 12 万 → 对应税率 20% 档 → 减半后实际约 10%，年缴约 1 万出头。**合规的真实成本远低于撸价格的利润**，别为逃这点税赌历史收入被穿透。

### 2.2 810 号令：平台报税机制（全文已核，国务院令第 810 号，2025-06-24 施行）
- **报什么**：平台每季度终了的次月内，向税务机关报送平台内经营者的**身份信息+上季度收入信息**
- **谁报**：所有电商平台（淘宝/拼多多/抖音/微信/小红书/京东……含境外平台在境内经营的）
- **首次报送**：2025 年 10 月完成首报，之后按季滚动
- **不追溯**：施行前的历史收入平台不报（但税务机关检查时仍可依法调取合同订单、交易明细、资金账户、物流信息——第 7 条）
- **配套**：税务可与市监、人社、网信等部门信息共享；平台瞒报漏报自己挨罚（2–10 万，严重 10–50 万）
- **现实中已发生**：首报后已出现税务向卖家推送风险提示、要求自查补申报的公开报道。大额长期零申报的店铺是重点核查对象
- **正确姿势**：开店即办照 → 按季如实申报 → 用足小规模优惠（多数新手实际税负极低）→ 成本费用留凭证（进货单/运费/推广费发票或收据，经营所得税前扣除全靠它）

### 2.3 跨境出口的海关代码与税收（一张表讲清）
| 代码 | 模式 | 适配 | 税务要点 |
|---|---|---|---|
| **9610** | 零售直邮出口（清单核放、汇总申报） | Temu/TikTok/速卖通直发单 | 综试区内可"无票免税" |
| **9710** | 跨境电商 B2B 直接出口 | 亚马逊 FBA 头程前的 B2B 批发 | 走一般贸易退税逻辑 |
| **9810** | 出口海外仓 | 半托管/海外仓/FBA | 退货可复运回；有"离境即退税"便利化试点（多地） |
| **1210** | 保税模式（入区出口/网购保税进口） | 平台保税仓发货 | 出区核放清单 |
| **1039** | 市场采购贸易（义乌等试点） | 档口拿货无票采购 | **免征不退**，单票 ≤15 万美元，结汇便利 |

- **综试区无票免税**：在跨境电商综试区（全国 165 个，覆盖绝大多数城市）注册的电商出口企业，采购无发票货物出口，可免增值税/消费税（财税〔2018〕103 号）
- **所得税核定**：综试区内符合条件的出口企业，企业所得税按**应税所得率 4%** 核定征收（税务总局公告 2019 年第 36 号）
- **出口退税**：有增值税专用发票才能退（退税率 6%–13% 视商品）。无票工厂货 → 走 9610 无票免税或 1039，别硬凑退税
- **收款结汇**：提现到国内个人卡/对公户均需贸易背景真实（第三方支付机构持外管局牌照，申报"货物贸易"项下），**别走地下钱庄**


## 3. 目的国合规：卖到哪，守哪的规矩

### 3.1 美国
- **关税**：见 02 章 §0（de minimis 已废，中国原产 = MFN + 301 强迫劳动 12.5% + 232 行业税），发货前让货代/报关行按 HS 编码预归类算税
- **品类认证**（平台与海关都可能查）：
  - 儿童产品：**CPC 证书**（CPSIA，需 CPSC 认可实验室测试）——玩具/童装/母婴必查
  - 带无线/蓝牙/WiFi 的电子产品：**FCC** 认证/声明
  - 食品接触材料、膳食补充剂、化妆品：**FDA**（食品设施注册/标签合规）
  - 电器：UL/ETL 非强制但被 Amazon 大量抽检（无证被下架常见）
  - 加州 **Prop 65** 警示标签（不含则可能被职业打假集团起诉）
- 电池/液体/膏体/磁性物品 = 敏感货，物流渠道受限，新手尽量避开

### 3.2 欧盟
- **CE 标志**：电子产品/玩具/个护等绝大部分品类必须，自我声明+技术文件
- **GPSR 通用产品安全法规**（2024-12-13 起）：所有消费品须有**欧盟境内责任人（欧代）**，包装/Listing 上标欧代信息+制造商信息，平台已强制核验——没欧代 = 下架
- **EPR 生产者责任延伸**：德国包装法（**LUCID** 注册，不注册即违法）、法国（Triman 标识 + 回收机构注册）；平台按国别代扣代缴的通道已上线，但注册义务仍在卖家
- **IOSS/VAT**：≤€150 的 B2C 直邮由平台（Temu/速卖通/TikTok）代收代缴 VAT，卖家无需自注册；自建站/自发货欧洲 >€150 或 B2B 需自行注册当地 VAT 税号
- **2026-07-01 起关税层**：€150 免税取消，过渡期每件 €3 临时关税（至 2028-07），之后按 HS 征税——定价必须把这块算进去

### 3.3 英国
脱欧独立体系：UKCA 标志（多数普通商品**仍认可 CE**，但留意品类清单更新）、英国 VAT（≤£135 平台代缴，以上自报）、EPR（英国包装税已生效）

### 3.4 日本/东南亚（简）
- 日本：电气 PSE、食品接触食品卫生法、无线电 TELEC
- 东南亚：印尼 2026-10-18 起**清真强制认证（Halal）**落地；泰国 TISI；马来西亚 SIRIM——做 Shopee/Lazada/TikTok 东南亚前查品类准入

## 4. 跨境收款工具（2026 主流五家）

| 工具 | 背景 | 提现费率区间* | 特点 |
|---|---|---|---|
| PingPong | 杭州持牌 | 约 0.3%–1%（常有 0 费率活动） | 平台覆盖最全，福贸做 B2B |
| 万里汇 WorldFirst | 蚂蚁集团旗下 | 约 0–0.6% | 与阿里系平台结算顺 |
| 连连国际 | 杭州持牌 | 约 0.5% 上下 | 老牌，提现快 |
| Airwallex 空中云汇 | 全球牌照 | 约 0–0.6% | 多币种账户强，适合独立站 |
| Payoneer | 美国上市 | 约 1%–1.2%（+汇损） | 亚马逊官方合作老牌 |

*费率随时调整、按流水有阶梯，开户均免费，以官网实时报价为准。
- 开户材料：执照/个体户 + 法人身份证 + 店铺后台截图；1–3 个工作日
- 合规性：均持外管局/当地金融牌照，结汇申报"货物贸易"，可提现到**经营者个人卡**（个体户）或对公户
- 新手建议：选一家覆盖你全部平台的即可，别多开

## 5. 物流成本坐标系（2026 经验区间，以实时报价为准）

**国内**（一件代发场景由供应商发货，自发货才用）：
- 义乌/潮汕小商品件：约 **¥1.2–2.5/单**（500g 内），全国通票 ¥2–4
- 大件/重货按 kg 计，家具家电另议；极兔/中通/圆通义价最低

**跨境直邮专线小包**（云途/燕文/4PX 等）：
- 常见克价 ¥40–80/kg 起 + 挂号费 ¥8–15/件，欧美 7–15 天
- 税改后务必确认渠道是 **DDP（预缴关税）** 模式——2026 年还给你走 DDU 免税的渠道本身就可疑

**海外仓/FBA**：
- 头程海运美西：快船约 25–35 天 / 普船 35–45 天，约 ¥1,000–2,500/CBM（波动大）
- 海外仓：仓储费 + 操作费（拣货打包 ¥2–5/件）+ 尾程派送（美国 $3–8/件视重量）
- 记账口径：海外仓模式每单物流成本 = 头程分摊 + 仓储 + 操作 + 尾程，**通常 ¥15–40/单**——低价品根本撑不起，选品时就该否掉

## 6. 知识产权：先注册再放大

- **国内商标**：官费 **¥270/类**（网申），代理另加 ¥500–1000/类；周期 8–12 个月；电商标配 = **35 类**（广告销售）+ 你的产品类（如 25 服装 / 3 美妆 / 9 电子 / 21 家居 / 5 食品）
- **美国商标**：USPTO 标准申请约 **$350/类**（2025 费改后）+ 必须委托美国执业律师（$300–800），周期 12–18 个月
- **欧盟商标**：EUIPO **€850**（含 1 类，加类 €50/€150），周期 4–6 个月，一件覆盖 27 国
- **亚马逊品牌备案**：R 标最稳（TM 受理号可试"待定"通道）；备案后才能开 A+ 页面、品牌分析、打击跟卖
- **防侵权**：上架前用 Google Images 反查外观、检索平台在售同款；亚马逊卖家的最大死因之一就是外观/发明专利投诉（TRO 冻结资金）——差异化设计 + 保留自己的设计底稿

## 7. 新手合规 Checklist（开店前逐项打勾）

- [ ] 办个体户执照（网络经营场所登记）
- [ ] 税务登记 + 选小规模纳税人
- [ ] 平台店铺实名 + 保证金缴纳决策
- [ ] 记账：进货、包材、快递、推广、平台扣点全部留凭证（Excel 月度流水即可起步）
- [ ] 按季申报增值税 + 经营所得税预缴
- [ ] （跨境）确定出口代码路径 9610/9810/1039 + 开通收款工具
- [ ] （跨境）目的国品类认证清单核对：CE/GPSR 欧代/EPR/CPC/FCC/FDA
- [ ] 商标申请排期（35 类+产品类先行）
- [ ] 每季度对账：平台结算额 vs 申报收入一致
