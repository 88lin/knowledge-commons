# 07 · 90 天执行计划（按周落地）

> 配合各章使用。原则：**前 30 天目标是"跑通"，不是"赚钱"**；每天投入 ≥2 小时才按此表执行，时间更碎就把周期 ×1.5。

---

## 第 1 周 · 定方向（读 README/01/02/06 章）

- [ ] 按 README 三条路径自测：本金/时间/能力，选定 1 个平台（**只选一个**）
- [ ] 办个体户执照（线上 1–3 天，见 06 §1.3）
- [ ] 注册税务，选小规模纳税人
- [ ] 平台官方免费课程过一遍开店部分（入口清单见 01 §9）
- [ ] 建立三张模板表格 + 每日数据看板（05 §2）

**产出**：执照 + 店铺开通申请 + 选定赛道方向

## 第 2 周 · 定品（读 03 章）

- [ ] 用免费工具（生意参谋/蝉妈妈 AI 会员/Google Trends）列 20 个候选品
- [ ] 每个候选做供需比初筛 → 剩 8 个
- [ ] 模板 02 十维评分 → 剩 3–5 个
- [ ] 模板 01 核价：净利率不达红线（35%/25%/15% 按平台）直接淘汰
- [ ] 1688 找每款 ≥3 家供应商，**全部拿样**

**产出**：3–5 个过了评分与利润线的品 + 到手样品

## 第 3 周 · 开卖（读 01/02 章对应平台节）

- [ ] 缴保证金决策、店铺装修、类目资质核对（跨境的查认证清单，06 §3）
- [ ] 上架 3–5 款：标题按公式写、主图 5 张按逻辑做、详情页 5 屏（痛点→方案→细节→保障→FAQ）
- [ ] 设精选联盟/买手佣金（抖音 ≥10% 起步、小红书开买手合作）
- [ ] 朋友/自然流首单跑通：下单→供应商发货→对账→回款全链路
- [ ] （跨境）开通收款工具、确定物流渠道（06 §4–5）

**产出**：店铺上线 + 全流程至少 1 单闭环

## 第 4 周 · 测款（读 04 章）

- [ ] 每款做 2 条素材，按 04 §3.2 脚本骨架产出
- [ ] 小额投流：抖音随心推 ¥100–150/条 或 淘宝直通车日限 ¥50–100×3 天
- [ ] 数据全部记入模板 03，按判断线执行"追/改/弃"
- [ ] 弃的款下架不恋战；过的款进入第 2 个月

**月度复盘**：花了多少、卖了多少、每单真实利润（模板 01 对账）、退款率、下次要改什么

---

## 第 2 个月 · 找到"跑通的款"并放大

- [ ] 把测款最优的 1–2 款集中资源：素材翻拍 3–5 版防疲劳
- [ ] 投放加码纪律：ROI >保本线才加预算，每天收盘审计划（04 §8 预算结构）
- [ ] 建立达人分销：精选联盟邀约 50–100 个中腰部达人（佣金 15–25%）
- [ ] 上游锁供：与跑量供应商谈账期/包销/备选产能，备份 2 家
- [ ] 差评与客服问题逐条归因，产品或详情页同步迭代
- [ ] （境内）开通店铺会员/粉丝群等平台内私域工具；（微信小店）开始企微沉淀

**目标**：单店日出 10–30 单稳定 2 周，净利率≥红线

## 第 3 个月 · 结构化放大

- [ ] 建立选品流水线：每周固定 4 小时按 03 章 SOP 筛新品、测 2–3 款，淘汰 2–3 款
- [ ] 价格结构落地：引流款/利润款/形象款三档（05 §3）
- [ ] 报平台活动：周五拼多多秒杀/淘宝日常营销/抖音大促节点
- [ ] 复盘税与合规：季度申报是否如期、成本票是否收集（06 §7 Checklist 过一遍）
- [ ] 现金流沙盘：按 05 §4 公式算放大所需资金，不够就控速——**别用信用卡额度补备货**
- [ ] 第二平台决策：只在第一平台稳定盈利后开（同货异平台的优先级见 01 §8 / 02 §8 决策树）

**90 天终点判断**：
- 跑通 ≥1 个月净利为正的款 → 进入常规运营，考虑放大/扩平台
- 三个月全部亏损但数据在改善 → 复盘选品方法（多数问题出在评分阶段没淘汰干净）
- 三个月毛利都算不平 → **诚实评估：这份生意在你的本金/时间下不成立**，止损也是合格的经营决策

## 附：每周固定动作清单（进常规期后）

| 周期 | 动作 |
|---|---|
| 每日 | 10 分钟数据看板（05 §2）+ 客服回复 + 发货对账 |
| 每周一 | 看平台官方公告/商家中心规则更新 |
| 每周三 | 素材产出与翻拍（≥3 条） |
| 每周五 | 测款数据复盘，执行追/改/弃 |
| 每月末 | 模板 01 全店对账 + 财务流水 + 税罐子核对 |
| 每季度 | 增值税/所得税申报（06 §2）+ 供应商年审（比价 2 家） |
