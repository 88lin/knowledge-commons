# 数据资源与实证路径 · 用数字说话

> 知识公社 · 社会主义实践研究中心 · 配套文档 05
> 铁律：**先查统计口径，再动手分析**。口径不对，全盘白做。

## 一、三层证据结构

| 层 | 内容 | 典型入口 |
|----|------|----------|
| 宏观 | 全国/分省年度面板：GDP、财政、收入分配、公共服务 | 国家统计局数据平台、统计年鉴、普查公报 |
| 中观 | 县域/城市面板、行业数据、政策文本库 | 政府工作报告库、部委数据、白皮书 |
| 微观 | 家庭/个人调查数据 | CFPS、CGSS、CHFS（注册申请，大多免费） |

## 二、实证研究的最小流程

1. 提出可检验命题（有方向、有机制）；
2. 找数据：口径定义、覆盖年份、缺失情况；
3. 描述统计先行——先画图再建模；
4. 稳健性：换口径、换样本、换方法各做一遍；
5. 结论写「证据支持/不支持什么」，不写「证明了真理」。
