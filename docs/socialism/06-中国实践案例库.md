# 中国实践案例库 · 研究的富矿

> 知识公社 · 社会主义实践研究中心 · 配套文档 06
> 五大实践场域，每个都按「政策原文 → 权威解读 → 数据证据 → 地方差异」四层组织材料。

## 一、五大场域与可研究问题

1. **脱贫攻坚与乡村振兴**：衔接机制、防返贫监测、集体经济治理；
2. **共同富裕与分配**：三次分配协同、县域公共服务均等化、示范区评估；
3. **经济体制改革**：国企改革绩效、营商环境、数据要素；
4. **基层治理与党建**：党建引领、驻村帮扶、全过程人民民主的基层形态；
5. **生态文明**：绿水青山转化的地方实践、生态补偿机制。

## 二、案例研究方法卡

- 选案：典型（最能体现机制）+ 可进入（能拿到材料）；
- 证据链：政策文本 × 统计数据 × 访谈/地方公报三角互证；
- 写作：机制故事化，结论克理化。
