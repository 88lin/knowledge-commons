# 国际视野与比较研究 · 比较的坐标

> 知识公社 · 社会主义实践研究中心 · 配套文档 07
> 两条线索：**其他社会主义国家的实践**（越南革新、古巴更新、老挝革新）与**世界社会主义思潮与运动**（文库档案、左翼期刊、国外中国研究）。

## 一、比较研究的三个用法

1. **机制对照**：越南「革新开放」与中国改革的同与异——回答「路径是否唯一」；
2. **文献述评**：国外左翼/主流学界对中国特色社会主义的研究——知己知彼，找对话点；
3. **资料互证**：马克思主义文库多语种档案用于文本校勘与思想史梳理。

## 二、使用须知

- 境外源直连不稳者，资源总库已标「国际网络」；校园网/文献传递常更顺畅；
- 外文材料引用须核对原文版本；译介期刊是二手文献，关键处回外文原文。
