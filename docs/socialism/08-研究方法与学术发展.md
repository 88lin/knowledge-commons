# 研究方法与学术发展 · 怎么写、怎么投、怎么走

> 知识公社 · 社会主义实践研究中心 · 配套文档 08
> 三件事：**方法工具箱 / 投稿与课题 / 升学与职业**。

## 一、方法工具箱

- 文献管理：Zotero（免费开源）+ GB/T 7714 著录规范；
- 检索组合拳：NCPSSD → 校图书馆知网/万方 → 文库档案 → 学术搜索引擎；
- 学位论文三件套：选题论证（真问题）+ 文献综述（有缺口）+ 研究设计（可执行）。

## 二、投稿与课题

- 期刊：只认主办单位官网投稿系统；CSSCI 目录以南京大学官网为准；
- 课题：国家社科基金（全国哲学社会科学工作办公室）、教育部人文社科项目——历年立项名单是选题风向标；
- 学术不端红线：查重、署名、数据造假一票否决，一开始就按规范来。

## 三、升学与职业

- 考博/申博：研招网 + 目标马院研究生院官网；研究计划书 = 小号的开题报告；
- 学术会议：全国马克思主义论坛、青年学者论坛等——听会也要投文章；
- 职业面：高校思政课教师、党政机关研究部门、智库研究员、中学政治教师（教资）。
