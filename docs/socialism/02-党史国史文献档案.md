# 党史国史文献档案 · 实践的时间轴

> 知识公社 · 社会主义实践研究中心 · 配套文档 02
> 方法：**通史打底 → 专题下钻 → 档案互证**。防「以论代史」；二手结论一律回溯一手文献。

## 一、三条时间轴（研究前先钉在墙上）

1. 革命史轴（1921–1949）：建党 → 土地革命 → 抗战 → 解放战争 → 建国；
2. 建设改革轴（1949–2012）：过渡时期 → 全面建设 → «文革»曲折 → 改革开放 → 市场经济体制；
3. 新时代轴（2012– ）：脱贫攻坚 → 全面小康 → 共同富裕 → 中国式现代化。

## 二、档案使用须知

- 中央级档案与文献：以中央党史和文献研究院、党的文献期刊、官方专题页为准；
- 地方与专门档案：各省档案馆数字馆、二史馆（民国史料）按题查；
- 口述与影像：注意记忆偏差，与文献互证后使用。
