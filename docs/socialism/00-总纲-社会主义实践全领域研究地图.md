## 一、什么是「社会主义实践研究」

社会主义实践研究 = 研究社会主义**从观念到现实**的全过程：

- **纵向**：空想社会主义 → 科学社会主义（1848）→ 十月革命（1917）→ 苏东实践与挫折 → 中国革命与建设 → 改革开放 → 新时代。
- **横向**：政治（政权与治理）、经济（所有制与分配）、社会（阶级与民生）、文化（意识形态与教育）、生态（人与自然）、国际（世界体系与外交）。
- **中国主战场**：中国特色社会主义的实践逻辑——为什么这么走、怎么走过来的、还行不行得通、对世界意味着什么。

一句话：**用文献说话、用档案说话、用数据说话**；把「立场、观点、方法」落到可检验的经验材料上。

## 三、四步研究法（本研究中心的总方法）

1. **读原著**——文本链：全集/选集 → 单行本 → 手稿与书信 → 权威注释。先读少而精的名篇，建立「原文感」，防止二手转述失真。
2. **通党史**——时间轴：通史打底 → 专题下钻 → 档案与文献集互证。防止「以论代史」。
3. **盯前沿**——期刊地图：核心期刊目录 → 免费全文库（NCPSSD）→ 会议与课题立项名单。找到「别人做到哪、还没做什么」。
4. **做实证**——证据链：统计口径 → 数据平台 → 调查数据/案例材料 → 分析与稳健性。让结论可以被检验、被反驳。

## 五、选题的「三交集」原则

好选题 = **现实真问题 × 文献有缺口 × 数据可获得**：

- 只有真问题没缺口 → 重复劳动；
- 只有缺口没数据 → 空对空；
- 只有数据没真问题 → 技术练习。

收窄公式：**「大方向 + 具体机制 + 可比对象/可测指标」**。
例：「共同富裕」→「县域基本公共服务均等化」→「浙江 90 县 2015–2024 基本公共服务支出均等化的财政转移支付效应」。

二十一个成建制选题方向见站内「选题库」。
