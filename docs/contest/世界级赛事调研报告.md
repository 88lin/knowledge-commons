## A. 世界技能大赛（WorldSkills）云计算项目

### A1. 项目概况（官方页面提取，来源：本地存档 ws_skill_545.html = https://worldskills.org/skills/page/545/ ）

- 官方标题：Cloud Computing | WorldSkills；元描述：云计算已成为企业数字化转型战略的关键部分，企业正把文件存储、本地服务器等实体 IT 活动迁入虚拟环境。
- 官方介绍要点：
  - 云计算专家帮助企业把实体 IT 活动（文件存储、本地服务器等）迁入虚拟环境；云工程师通常就职于科技公司或拥有大量基础设施的大型企业。
  - 该技能是在**公有云环境**中设计并实现 IT 基础设施，涉及系统工程师、数据库管理员、网络工程师、存储管理员、系统/网络/解决方案/企业架构师、程序员/开发者等多种角色。
  - 职责包括：提供设计输入、与客服和分析师协作推进项目里程碑、分析弱点并建议系统改进；需要系统架构组件（网络、软件）背景，以及出色的协作与分析推理能力。
  - 擅长管理多云环境（来自不同厂商的公有云、私有云、混合云）的人才将最有市场竞争力。
- "适合你如果你喜欢：复杂问题、使用计算机"。
- 官方合作伙伴：Amazon Web Services（AWS Educate 链接挂在技能页）。
- 官方职业标准入口：WorldSkills Occupational Standards（WSOS）—— https://worldskills.org/what/projects/wsos/
- 官方历年成绩入口：https://results.worldskills.org/results?base_skill=545
- 中国组委会（人社部）对项目的界定（来源：http://worldskillschina.mohrss.gov.cn/c/2020-08-07/611.shtml ）：
  - **单人赛**；2022 上海周期参赛选手须为 1996 年 1 月 1 日以后出生。
  - 云计算项目是"在公有云环境中实现和完善完整的、面向实际工作场景的信息化系统"的竞赛项目，涉及**环境创建、业务部署、综合运维**几个部分。
  - 技能要求：依据行业规范和标准，选择、创建和配置适合的公有云服务，部署信息化系统并进行自动化维护与实时故障排除；综合运用网络架构搭建、操作系统配置、应用程序部署、程序脚本编写，实现系统高性能、高可用、安全、弹性和低成本。
- 对照说明：id=449 的技能页（本地 ws_skill_449.html）为 "Page Not Found"，证实云计算技能 id=545 正确；现行官方 URL 为 https://worldskills.org/skills/page/545/ （已验证 200）。

## B. 世界职业院校技能大赛 云计算赛项

### B1. 2022 首届（天津主赛区）

来源：http://tianjin.china.com.cn/2022-08/11/content_42067749.htm （中国网，供稿：天津城市职业学院）；http://tj.news.cn/ztbd/2022sjzjdh/2022-08/11/c_1128906674.htm （新华社天津频道转《今晚报》，记者李杨）；http://www.tjyun.com/system/2022/08/10/052987047.shtml （津云）；https://baike.baidu.com/item/%E4%B8%96%E7%95%8C%E8%81%8C%E4%B8%9A%E9%99%A2%E6%A0%A1%E6%8A%80%E8%83%BD%E5%A4%A7%E8%B5%9B/60709501

- 2022 年 8 月 10 日，首届世界职业院校技能大赛云计算赛项在**天津城市职业学院**开赛；大赛由教育部、国家发展改革委、科技部、工信部、天津市人民政府等 35 家单位联合主办（百度百科口径）。
- **中外混合编队**：每队 4 名选手 = 2 名中国学生 + 2 名外国学生。
- 规模：来自全国 11 个院校、10 多个国家，共 44 名选手"云上同台竞技"。
- 赛场架构：天津为主赛场，同时竞技的还有重庆、湖南及境外等多个赛场；11 所参赛院校作为分赛场，比赛视频接入主赛场大屏实时显示，英语教师通过腾讯会议等与境外选手沟通、实时监控。
- **比赛内容**：围绕社会岗位需求、紧贴生产实际，从业务需求与工程应用环境入手，选手完成**私有云、容器云、公有云**三方面的部署、运维、安装、调试（指导教师张铧、刘颖口径）。
- 首届云计算赛项最终获奖/冠军名单：未公开（公开报道仅见开赛与过程报道，未检索到该赛项获奖公告）。

### B4. 2025 年（第三届，全面赛道制 + 海外赛区）

官方文件：教育部《关于印发〈2025 年世界职业院校技能大赛实施方案〉的通知》（教职成函〔2025〕4 号，2025-06-09 印发）—— http://www.moe.gov.cn/srcsite/A07/s7055/202506/t20250617_1194543.html

- 主题："技炫青春 能创未来"（Skilled Youth, Shining Future）。
- 赛道：共 **42 个赛道**（不再按单个"赛项"设置；参赛队结合专业围绕生产、管理、服务一线真问题、真场景**自主确定参赛项目**）。
- 赛制：初赛、复赛、总决赛三级；总决赛分**争夺赛、排位赛、冠军总决赛**三阶段；争夺赛由国内赛区和海外赛区实施，排位赛与冠军总决赛由天津赛区实施。
- 时长：争夺赛每个项目比赛时长不超过 1 小时；排位赛、冠军总决赛每个项目 10 分钟（须有核心技能实践操作）。
- 评分要素：技能水平、职业素养、应用价值、团队合作、创新创意五方面按权重整体评价。
- 组队：以学校为单位组队，团体赛每队不超过 4 人；国际组每队中国籍选手不超过 1 人；指导教师每队不超过 2 名（国际组外籍指导教师不少于 1 名）。

## C. 金砖国家职业技能大赛 云计算赛项（BRICS-FS-11）

### C1. 2024 年技术规程全文要点摘录（原件 PDF，全文提取文本见 `research/pdf/brics_cloud_regulation.txt`）

- 文件：《金砖国家职业技能大赛（金砖国家未来技能和技术挑战赛）云计算 BRICS-FS-11 技术规程（省级/区域选拔赛）》，2024 年 2 月。原件由前次调研留存于 `cloud-competition/brics_cloud_regulation.pdf`（提取过程未改动原件）；金砖大赛官方发布渠道为 www.brskills.com（赛题公布页 http://www.brskills.com/jzzy/productjs.html ）。
- **赛项名称与编号**：2024 金砖国家职业技能大赛（金砖国家未来技能挑战赛）云计算，赛项编号 **BRICS-FS-11**。
- **赛制**：区域选拔赛为**线下双人赛**；竞赛由专业云计算技能竞赛云平台提供云资源构建竞赛环境和考核系统，选手通过线上线下方式完成任务考核（决赛阶段为线上国际 + 线下国内相结合）。
- **技能范围（六大工作技能）**：
  1. 云主机硬件配置、操作系统安装、网络配置、常用应用服务搭建（yum、数据库、WEB、FTP、NFS、DNS、SSH 等）；
  2. 虚拟化技术（KVM）、OpenStack 私有云平台搭建及组件运维（Keystone、Glance、Nova、Neutron、Cinder、Swift 等）；
  3. Shell 脚本运维管理（云主机/云存储/云网络/云数据库）、云应用项目部署与故障排除；
  4. Docker 容器技术、私有容器仓库部署；
  5. Kubernetes 容器编排（Pod 管理、Yaml 模板部署、负载均衡、自动伸缩、DevOps 一体化）；
  6. 资源管理、状态监测、故障恢复与自动化运维工具（Ansible、Puppet、Zabbix、Prometheus、HAProxy、Keepalived 等）。
- **技能标准（Skill Specification）权重**：

| 部分 | 权重 |
|---|---|
| 私有云平台搭建 | 15% |
| 云平台管理和运维 | 15% |
| 容器的搭建 | 15% |
| 容器编排工具的使用 | 15% |
| 自动化运维工具的使用 | **40%** |
| 合计 | 100% |

  （规程注明：评分方案按标准分值执行，允许 5% 变动，不得改变标准赋权——与世赛 WSOS 同一原则。）

- **模块划分、时长与分值**：

| 模块 | 名称 | 时长 | 分值权重 |
|---|---|---|---|
| A | 私有云平台的搭建与运维 | 240 min（三模块合计） | 30% |
| B | 容器的编排与运维 | （同上） | 30% |
| C | 企业级应用的自动化部署和运维 | （同上） | 40% |
| 合计 | — | **240 分钟** | 100% |

- **各模块作业内容（摘要，详见提取文本 4.4 节）**：
  - 模块 A（考核重点：OpenStack 私有云搭建部署与多服务资源运维管理）：物理主机 OS 设置管理（网络/存储/虚拟化/安全）、网络连通性测试、安装配置 Yum 源/FTP/NTP/HTTP/RabbitMQ/MariaDB/Memcached/Etcd、安装脚本搭建私有云并检查组件状态、Keystone/Glance/Nova/Neutron/Cinder/Swift 组件运维 + Shell 脚本运维、Python 脚本调用 OpenStack API 运维管理、故障排除保障私有云稳定运行。
  - 模块 B（考核重点：Docker + Kubernetes 编排、应用部署性能监控与故障预警）：Docker 服务安装与私有仓库部署、K8s 平台架构设计与模板文件编写搭建容器云平台、平台命令与运行状态检查监控、镜像/容器/仓库/网络基础运维、Dockerfile 与 Commit 制作私有镜像、K8s 运维（Pod 管理、Yaml 部署编排、负载均衡、自动伸缩、DevOps 一体化）。
  - 模块 C（考核重点：自动化运维与云上应用部署）：Ansible 多节点集群部署/集群运维/批量命令、常见应用运维（数据库、文件存储共享、Web、迁移）、Prometheus 定义监测指标与告警规则实现高可用与自动故障恢复、云上应用项目部署（私有博客系统、应用商城网站等）、Shell 脚本运维任务（数据库备份、一键部署、服务状态检测）。
- **评分方案**：
  - 评分由裁判组**线下现场**完成；作弊或违规按情节处理，严重者取消成绩。
  - 排序规则：总成绩高者在前；同分按**模块 C → 模块 B → 模块 A** 的次序，模块成绩高者在前。
  - 评测依据（不限于）：完成云平台搭建和验证平台运行状态；创建容器并部署应用上云平台；实现云平台应用的管理与运维；完成对企业应用的自动化部署和运维。
- **赛题（Test Project）机制**：赛题由三个相对独立又联系的模块组成；赛题通过网站 http://www.brskills.com/jzzy/productjs.html 公布；**正式比赛前赛题进行 30% 改动**。
- **环境与设备要求**：
  - 技术平台：华为云服务平台 ×1（须可登录华为云 IAM 账户）+ 竞赛系统平台 ×1（须可测试访问和提交）。
  - 基础设施：见"2022 金砖国家职业技能大赛线下竞赛云计算赛项基础设施清单"（规程引用件）。
  - 参赛选手工具箱：自备工具须经技术专家批准；特殊工具由首席专家宣布。
- **技能特定规则（节选）**：
  - 禁止携带存储卡或任何便携式存储设备（USB）入场；
  - 参赛者不得携带个人笔记本电脑、平板、手机入场（专家和口译人员可用）；
  - 个人拍照录像设备须在测试项目完成后或经首席专家同意方可使用；
  - 由首席专家指派专业水平最高的主管专家记录测试项目点完成情况，对评估公平性负全责；
  - 非选手过错的技术故障：补偿从发现缺陷到完全消除缺陷的时间；选手过错则不补时；
  - PPE（口罩等个人防护用品）由参赛者自备。
- **组织与安全**：设比赛安全保障组（组长由赛项执委会主任担任）、与公安消防等部门联动、赛题命题/保管/发放/回收/评判安全专案、参赛单位须为选手购买人身意外伤害保险等（详见提取文本第 6 章）。
