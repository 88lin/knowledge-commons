先回答一个高频问题：世赛云计算是不是就考 AWS？

是 AWS，但不只是 AWS。

  • AWS 是 WorldSkills 的全球合作伙伴，世界技能大赛云计算项目（Trade / Skill 39）长期以 AWS 公有云作为公有云平台——所以「公有云架构」那一模块基本就是 AWS 主场。
  • 但一届比赛通常 4 个模块，覆盖 Linux 系统、Windows/AD、公有云架构（AWS）、自动化与故障排查。Linux、Windows/AD、网络服务这些模块跟 AWS 没关系，得靠实训打。
  • 各国风格差别很大：世界赛 / 欧洲赛偏传统基础设施 + 网络服务 + 故障排查（AWS 只是其中一块）；韩国赛是 AWS 全家桶 + Terraform + EKS + GitOps + 性能 SLO + 成本优化，接近真实 SRE；中国国赛（职业院校技能大赛云计算赛项）是 OpenStack 私有云 + 容器云 + 公有云三件套，偏技术栈广度。
  • 成绩坐标：2024 里昂金牌中国队黄佳杰，2022 特别赛金牌陈新源（深圳技师学院），下一届上海 2026。

所以这批 AWS Educate 课怎么用：它最适合把「公有云架构」那一块的底子打扎实，顺带把 AWS 控制台、核心服务、区域与可用区这套世界观建立起来。 但它不覆盖 Linux / Windows AD / 网络服务那几个模块——那部分要另走实训路线（见 云计算备战中心 / 实战训练场）。 两手都硬，才够到世界级水平。

推荐刷课顺序（按这条线走，约 30 小时）

  1. 第一阶段 · 打地基（13 小时）：云计算入门 101 → 存储入门 → 计算入门 → 网络入门 → 数据库入门 → 安全入门。
    这 6 门是 AWS 官方设计的基础闭环，按顺序刷，别跳。
  2. 第二阶段 · 上手控制台（4 小时）：AWS 管理控制台入门（本站有全文） → 云运维入门 → 无服务器入门 → 云支持工程师的一天。
    到这一步你应该能不看教程自己找到任意服务。
  3. 第三阶段 · 真动手（4 小时）：用户数据处理实战 → 用 EC2 Instance Connect 登录 Linux 实例 → Amazon EBS 快照实战 → CloudWatch 入门。
    这 4 门是「Working with…」系列，要真开资源练，注意账单。
  4. 第四阶段 · 追 AI（10 小时）：机器学习基础 → 生成式 AI 入门 → Amazon Bedrock 入门 → Amazon Q Developer 入门 / 使用 → 负责任的人工智能入门。
    面向 AWS Certified AI Practitioner 认证方向。

怎么开始学

  1. 登录 awseducate.com（18 岁以上走 AWS Builder ID，有邮箱密码的走 Email and Password）。
  2. 左侧菜单进 Courses & labs —— 就是这 71 门课的列表。
  3. 点课程卡片 → 弹窗点 Confirm 选课 → 进入学习；进度会自动记录，卡片上显示百分比。
  4. 学完可拿数字徽章；徽章课完成后能进 AWS Emerging Talent Community（注意：该社区与 Job Board 公告将于 2026 年退役，课程本身不受影响）。
