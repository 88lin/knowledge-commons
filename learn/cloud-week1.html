本周七张卡 · 打勾前进

Day 1 · 装机（30–45 分钟）

① 去 virtualbox.org 装 VirtualBox → ② 去 清华镜像 下 Ubuntu 24.04 ISO（桌面版，约 5GB，下着的时候正好做 Day 2）→ ③ VirtualBox 新建虚拟机：内存 4096MB / 硬盘 25GB → 挂 ISO 装系统 → ④ 装完拍快照，命名「L0-干净系统」。完成标准：能开机进桌面 + 快照存在。卡了截图来问。

Day 2 · 看两样东西（40 分钟，手机可做）

① 学堂里看「世赛」板块第一课视频 → ② 读第 0 章 · 开始之前（15 分钟）。完成标准：用一句话说出「服务器、虚拟机、云计算」三者的关系——说得糙没关系，说出来就算过。

Day 3 · 终端初见（60 分钟）

打开虚拟机里的终端（Ctrl+Alt+T），跟着第 1 章前半学：pwd / ls / cd / mkdir / touch。完成标准：不看资料，在 home 目录建出 cloud/week1/ 两层目录和一个 note.txt。

Day 4 · 文件与权限（60 分钟）

第 1 章中段：cp / mv / rm / cat / chmod / sudo 是什么。完成标准：把 note.txt 权限改成 600，并能一句话解释 600 是什么意思。

Day 5 · 第一次装服务（60 分钟）★ 本周高潮

sudo apt install nginx -y → 改首页：echo "我的第一个站点" | sudo tee /var/www/html/index.html → 浏览器开 http://localhost 看到你的字。完成标准：看到自己写的页面——这一刻你就已经超过大多数"想学云计算"的人了。

Day 6 · 远程连接（45 分钟）

VirtualBox 网络设置加一条端口转发（主机 2222 → 虚拟机 22），在宿主机终端 ssh 用户名@127.0.0.1 -p 2222 进虚拟机。完成标准：在宿主机的黑窗口里远程操作你的 Linux——这就是运维的日常姿势。

Day 7 · 第一次评分 + 复盘（45 分钟）

跑一次 L1 评分（实训场有命令），不要求分高——看看能拿几分，FAIL 的每一项就是你下一周的地图。再做一轮模拟训练十题对比 Day 2 之前的自己。拍快照「W1」。完成标准：知道自己的分数和差距——然后回来找我，我按你的进度排第二周。
